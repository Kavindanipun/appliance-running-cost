# Appliance Cost SEO Test

A free GitHub Pages experiment for testing US/UK search demand around appliance electricity running costs.

## Publish
1. Create a new public GitHub repository (suggested name: `appliance-running-cost`).
2. Upload `index.html`, `style.css`, `app.js`, `robots.txt`, `sitemap.xml`.
3. Settings → Pages → Deploy from branch → `main` → `/(root)`.
4. After the site is live, replace `SITE_URL` inside `sitemap.xml` with the exact GitHub Pages URL.
5. Add the URL-prefix property to Google Search Console, verify it, submit `sitemap.xml`, then request indexing for the home page.

## Calculator note
This is an estimate based on watts × time × electricity unit rate. Cycling/variable-power appliances may consume less than their rated wattage over clock time.
